# Aula 7 — Avaliação & Desenvolvimento

## 📌 Tópicos principais

### 1. Treinamento vs. Desenvolvimento (T&D)

**Treinamento (T):** ensina competências específicas para o cargo atual
- Foco no curto prazo
- Preparar para a função atual
- Resposta a problemas imediatos

**Desenvolvimento (D):** prepara pessoas para desafios futuros
- Foco no longo prazo
- Preparar para funções futuras
- Crescimento contínuo

### 2. Taxa Média de Retenção (Pirâmide da Aprendizagem)

| Método | Retenção |
|--------|----------|
| Palestra / Aula expositiva | 5% |
| Leitura | 10% |
| Áudio/Visual | 20% |
| Demonstração | 30% |
| Discussão em grupo | 50% |
| Prática fazendo | 75% |
| **Ensinar outros / Aplicar imediatamente** | **80%** |

**Conclusão:** Quanto mais ativo o aprendizado, maior a retenção. Por isso dinâmicas e prática valem mais que palestras.

### 3. Aprendizagem Individual (Modelo de Kolb)

**Ciclo experiencial de Kolb:**
1. **Experiência Concreta** — fazer algo
2. **Observação Reflexiva** — refletir sobre o que aconteceu
3. **Conceptualização Abstrata** — entender o porquê
4. **Experimentação Ativa** — aplicar o que aprendeu

### 4. Plano de Desenvolvimento Individual (PDI)

**O que é:** Ferramenta para mapear e planejar o desenvolvimento de cada colaborador.

**Elementos típicos:**
- Competências a desenvolver
- Ações concretas (cursos, mentorias, projetos)
- Prazo
- Indicador de sucesso

### 5. Universidade Corporativa

| Centro de T&D Tradicional | Universidade Corporativa |
|---------------------------|---------------------------|
| Foco em treinamento | Foco em aprendizagem contínua |
| Reativo | Proativo |
| Capacitação técnica | Desenvolvimento de lideranças |
| Programas pontuais | Programas integrados |
| Baixo investimento | Alto investimento |

### 6. Avaliação de Desempenho

**Tipos:**

**Quantitativa:**
- Metas claras, números e indicadores
- Objetividade
- Exemplos: ROI, vendas, produtividade

**Qualitativa:**
- Comportamentos observados
- Avaliação por competências
- Subjetividade
- Exemplos: liderança, colaboração

**Avaliadores:**
- Gerente imediato
- Autoavaliação
- Pares
- Subordinados (upward feedback)
- Avaliação 360° (múltiplos avaliadores)

**Consequências da avaliação:**
- Identificação de talentos
- PLR (Participação nos Lucros)
- Promoção
- Plano de desenvolvimento
- Demissão por baixo desempenho

**Cuidado:** Avaliação constrangedora = processo mal desenhado (torna-se punitivo ao invés de desenvolvimental)
